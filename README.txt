寄件成本计算器

1. 双击 index.html，用 Chrome、Edge 或 Safari 打开。
2. 把 .xls、.xlsx 或 .csv 快递账单拖进页面。
3. 页面优先显示总价格、总件数、均价；点开月份可查看首重件数和重量分段。
4. 默认规则：1kg 内 2.5 元；超过 1kg 的部分按 1kg 向上进位，每 1kg 1 元。
5. 右上角“设置”可修改首重重量、首重价格、续重价格、面单单价、续重步长、进位方式、自定义公式和重量分段。
6. 默认“导入后自动导出”已开启。也可随时点击“导出统计表”。

识别要求
- 推荐列名：寄件时间、内部计费重量、运单编号。
- 同时兼容常见近似列名，例如发货时间、揽件时间、计费重量、结算重量、快递单号。
- 月份优先从每一行的寄件时间提取，不依赖工作表名称。
- 多文件同时导入时，会按运单编号自动跳过重复记录。

数据说明
- 所有计算都在当前浏览器本地完成，表格不会上传。
- 设置保存在当前浏览器中，下次打开仍会沿用。
- 默认面单单价为 2 元/个。补差价 = 快递总成本 − 总件数 × 面单单价。
